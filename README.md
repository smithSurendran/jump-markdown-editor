# 📝 Real-Time Markdown Editor

A simple yet powerful two-pane Markdown editor built with **React + Vite**, featuring:

- Real-time preview of Markdown content
- Export rendered content to PDF
- Copy raw Markdown to clipboard
- Responsive layout and clean UI

---

## 🚀 Features

| Feature               | Description                                      |
|-----------------------|--------------------------------------------------|
| 🖊 Live Markdown Input | Type Markdown on the left and preview it on the right |
| 📄 Export to PDF      | Renders the right pane and saves it as a PDF file |
| 📋 Copy               | Copies the raw Markdown input to your clipboard |
| 📏 Word Count         | Displays word count and formatting tips         |

---

## 🔧 Tech Stack

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Marked](https://github.com/markedjs/marked) – Markdown parser
- [html2pdf.js](https://github.com/eKoopmans/html2pdf) – PDF generator
